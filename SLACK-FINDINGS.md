# #odin--ideation findings (Chrome sample, 29 Oct 2026, ~45 msgs / 19 threads)

Source: Claude-in-Chrome report (full: https://claude.ai/artifact/UrZ3PpLksw1sUNXkFAqV3G). All answers came from the Maven bot, not human staff. No accepted/rejected outcomes were seen.

## Rules stated by Maven
- Submit: Studio -> Tasks -> "Odin Production Full Workflow" -> + Create Task -> idea form -> Submit idea -> track in My Tasks. Wait for approval before recording.
- Idea form: goal, starting materials, apps, what you produce/decide, how you verify it, previous work.
- Recording length allowed: 15:00-50:59 incl. intro/epilogue (Maven's examples: 25/30/40 min). NOTE: orientation video said 15-20 min for a first task.
- Opening phrase: "I will be beginning my task soon. Here is the workflow I have in mind." Under 20 s, then minimize Goal doc without reading it.
- Figma banned for new work. Word, Chrome, Excel "not restricted"; Sheets/Docs answers conflicting; Affinity Photo unconfirmed.
- Commercial licensing applies to every app. Studio idea review decides approval.
- Studio bugs, login, Insightful, TaskRecorder ZIP errors -> helpdesk channel.

## What Maven's good ideas share
Own domain judgment + a checked result (not app navigation); synthetic self-made starting materials with analysis left for the recording; one named deliverable file; named apps; a verification step; one decision / one scenario; goal as a "X needs Y" sentence.

## Mistakes flagged
Vague scope ("end-to-end"); undecided apps; goal not matching the question; real employer/client data; swapping business names only; app navigation as the task.

## Open questions
Task Description vs approved Goal; Sheets/Docs status; Affinity Photo; recovering from TaskRecorder 2.4.4 ZIP failure; whether fictional-data analysis counts as expertise; how distinct ideas must be.

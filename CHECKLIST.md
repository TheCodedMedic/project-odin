# Odin task checklist (from the First Task Orientation video; verify vs Writer Guidelines)

## Choose the task
- Work you know; judgment-heavy, not extra steps. Clear goal, substantive work, useful result.
- First task: ~15-20 min recording. Split big tasks into two.
- 3 apps preferred if each adds value; 1-2 fine if the task is complex.
- Input files optional; prepare before recording. Gemini-prepared inputs OK (Gemini watermark only).
- No AI tools shown/used during recording or to generate/revise task content.

## Propose idea in Studio
- Goal, starting point, apps, expected result. WAIT for approval. Re-request approval if plan changes materially.
- App categories: Banned = no; Limited-use = <20% rule + any stricter conditions; Preferred-alternatives = allowed; Unrestricted = no approval. Missing app -> "other" with exact name.

## After approval (status: in progress)
- Copy ONLY the goal section, word for word, into: TaskRecorder, opening document, request section of metadata.rtf.
- metadata.rtf: apps in order used (repeat each return), approved goal, task steps.
- Hide the approval ID when recording.

## Before recording
- Launch apps, sign in, load, open files, then minimize. No private info, personal tabs, emails, notifications.
- Only the goal doc visible behind TaskRecorder.

## Recording
- Start, minimize TaskRecorder, say "I will be beginning my task soon. Here is the workflow I have in mind." (<20 s).
- Close/minimize goal doc, bring apps forward. One take, whole task.
- Narrate like teaching a colleague; name controls ("click the blue Export button top right"); explain decisions; point with cursor.
- Keep menu bar, clock, dock visible. No full-screen, no stacked ordinary windows (side by side is fine). Temporary dialogs OK, close when done.
- No typing/mouse inactivity/silence >45 s.

## Submit
- Upload 4 files: Video.mp4, original TaskRecorder zip (intact), deliverables.zip, metadata.rtf (own field).
- Run both AutoQC checks; fix or dispute every major flag (dispute with reasons + timestamps). Minor flags = advice.
- Never edit the production recording; re-record in same task if needed.
- Complete checklists honestly, click "Submit for review" (saving alone does not submit).

## Help
- Ask Maven first -> #odin-ideation (tasking) or Odin helpdesk (technical/onboarding). Include task link, step, expected vs actual, screenshot. Ask for escalation if stuck.

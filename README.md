# Project Odin (Mercor) - working notes

Status: initial research. Sources are third-party (blogs, X posts), not Mercor. Verify everything against the official offer, contract and dashboard.

## What it is
Paid contractor work for Mercor on behalf of an unnamed frontier AI lab. You complete a real computer workflow (macOS apps, automation, coding, STEM work), screen-record it with narration, and submit it for review. Researchers use the recordings to study how people work in software.

## Roles reported
- Computer power users / automation builders (Shortcuts, Automator, AppleScript, Keyboard Maestro, Zapier, Make)
- Software developers
- STEM researchers (MSc/PhD or enrolled)

## Requirements reported
- Mac running macOS 15+ (some listings say Apple Silicon M1+; others allow Intel)
- Stable fast upload, plenty of free disk space
- Tools: TaskRecorder 2.4.4 (.dmg from dashboard), Insightful (time tracking), Okta Verify (MFA for Mercor Studio)
- Separate macOS user profile and a non-personal "expert" email, so no personal data shows on screen

## Workflow reported
1. Verify offer and contract (hourly vs per-task, onboarding pay, revision rules, limits)
2. Onboard, install the approved tools
3. Ideate in Slack `#odin--ideation` with the `@Maven` bot
4. Pitch in Mercor Studio (Okta login, Odin world, "+ Create Task"). Wait for "Idea Approved: Start Recording"
5. Prepare synthetic data beforehand
6. Record with TaskRecorder: tidy tiled windows, only the 2-3 approved apps, narrate key decisions, 3-4 min wrap-up
7. Check the file opens, upload to the Studio task card, submit

## Rejection causes reported
Missing steps or result, overlapping or obscured windows, audio failure, personal or confidential info visible, unapproved apps, wrong format, unclear demonstration.

## Pay (conflicting reports)
$40/hr, $50-60/hr, $50/task, $100/task. Unclear whether onboarding, prep and rejected work are paid. Track real hours versus approved pay.

## Update: from the official Studio task page (user-supplied, Oct 2026)
This supersedes the third-party notes above where they conflict.

- Project: Odin trains AI to do tasks on macOS. You record your screen doing a realistic task from your own expertise, narrating what and why.
- Mac: Apple silicon (M1+) OR Intel, macOS 15+, 35 GB free. Intel uses `TaskRecorder2.4.4-Intel.dmg`.
- Pay: onboarding = 3 hrs + $400 (paid on task submission, so keep going past the 3 hrs). Trial = 12 paid hrs for 3 quality tasks. Production = up to ~2x pay for consistently high-quality tasks with few retries.
- Insightful (time tracker, @mercor.expert login) must be running while working. Stay within hourly/weekly caps.
- Source of truth: Writer Guidelines + Writer Handbook (Okta at c-mercor.okta.com -> Google Drive).
- Flow: Idea -> automated Idea Check (~1 min, must pass) -> set up TaskRecorder -> record -> upload -> submit.
- Idea must have 5 headings: Domain/Role, Goal, Starting materials, Steps (with apps per step), Deliverable. Apps listed again in the Apps field. Missing or inconsistent items are the top reason ideas are sent back.
- Rules: no RESTRICTED apps (list not seen), no AI while recording, free files only (CC0/public domain), Safari/Chrome allowed (10/22), TextEdit banned except for `metadata.rtf`, avoid desktop Excel (use Google Sheets / Excel web).
- Help: Slack `#odin--ideation`, tag Maven.
